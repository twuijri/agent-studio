# نطاق معرفة التطوير

هذا المجلد مخصص لإعدادات ونتائج `Understand-Anything`، وليس حالة تشغيل Studio.
الأداة واعتمادياتها مثبّتة خارج المشروع. انظر `docs/KNOWLEDGE-WORKFLOW.md`.

الحالة الأولية: نطاق مسح محدود مقترح في `.understandignore`، بانتظار اعتماد
المستخدم قبل أول تحليل. **لا توجد خريطة مكتملة ولا أساس تحديث تدريجي بعد.**
عند نجاح المسح والتحقق والبصمات، حدّث هذا السجل بالنطاق الحقيقي وتاريخ التحليل،
ولا تصف الخريطة الجزئية بأنها تغطي كل المشروع.
