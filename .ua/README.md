# نطاق معرفة التطوير

هذا المجلد مخصص لإعدادات ونتائج `Understand-Anything`، وليس حالة تشغيل Studio.
الأداة واعتمادياتها مثبّتة خارج المشروع. انظر `docs/KNOWLEDGE-WORKFLOW.md`.

اعتمد المالك النطاق الكامل بتاريخ 2026-09-18: الكود والاختبارات والتوثيق
وإعدادات البناء، باستثناء الأسرار وبيانات التشغيل والملفات الثنائية والمولّدة.
ملف `.understandignore` هو المرجع الدقيق للاستبعاد، و`config.json` يختار الشرح
بالعربية ويعطّل التحليل التلقائي عند كل commit.

**الحالة الحالية: اكتمل التحليل المحلي والتحقق البنيوي بتاريخ 2026-09-18.**
الجرد يحوي 2,123 ملفًا موزّعة على 102 دفعة؛ الخريطة تحتوي 9,283 عقدة
و23,153 علاقة و10 طبقات وجولة عربية من 14 خطوة. راجع [تقرير الجودة](QUALITY.md)
و`docs/changes/2026-09-18-twuijri-knowledge-map.md` للفحوص والحدود.
المرجع البرمجي هو `d2d95e616a8d0c1e6d1f5bb73090e29547a322f6`، مع توثيق هذه المهمة المحلي.
تقدم الفرع الرئيسي لاحقًا إلى `3584f31c`؛ تعديل وضع سطح المكتب المرتبط بالسيرفر
غير مشمول في هذه اللقطة، ويحتاج تحديثًا جزئيًا قبل الاعتماد على خريطته.
ابدأ بالخريطة لتحديد الملفات المعنية، ثم اقرأ نسختها الحالية واختبر تعديلك.
لا توجد خدمة عامة أو إضافة داخل التطبيق؛ تشغيل العرض وتعليمات الفريق في دليل المعرفة.

هذه خريطة للكود الموجود في المستودع فقط؛ لا تشمل بيانات المستخدم أو كود
Hermes Agent الخارجي الذي يُنزّل عند التشغيل. تغطية الملفات لا تضمن استخراج
كل علاقة ديناميكية. مكونات Vue تحتاج قراءة تكميلية لأن المحلّل البنيوي المثبّت
لا يستخرجها، وتبقى مراجعة التنفيذ والاختبارات ضرورية قبل التعديل.
