# فرع mobile: استيراد تطبيقي الأندرويد والآيفون وخطة البناء

المسؤول: twuijri
الفرع: mobile (طويل الأمد)
الحالة: جارٍ

## المشكلة والهدف
المالك يريد بناء تطبيق جوال أصلي «Core Hub Mobile» داخل هذا المستودع ليتابع
ميزات الويب وسطح المكتب، على فرع مستقل حتى النضج.

## القرار والموافقات
- الموافقة: المالك (2026-09-19: «خله بنفس المستودع بس حاليا نخليه ببرانش
  مستقل لين يوصل للنضج»).
- استيراد محتوى `twuijri/hermes-studio-mobile` (v1.4.0) إلى `clients/android`
  (يستبدل العميل القديم) و`clients/ios` و`clients/mobile-docs`، بلا تعديل.
- الخطة والقرارات في `docs/mobile/PLAN.md` بعد تحليل مستودع المالك وتطبيق
  Ekko الرسمي (APK عام، للفهم فقط: بنية uni-app، مسار الصوت، العقد؛ لم يُنسخ
  منه كود ولا أصول).

## الملفات والتأثير
`clients/android`, `clients/ios`, `clients/mobile-docs`, `clients/MOBILE_VERSION`,
`clients/check-mobile-version.sh`, `docs/mobile/PLAN.md`.

## الفحوص
- لا كود سيرفر/ويب متأثر. بناء الأندرويد يُتحقق في M1 عند إضافة سير العمل.

## المخاطر والرجوع
- الفرع مستقل ولا يُدمج في `main` قبل النضج.

## التسليم والخطوة التالية
M1: العقد (OpenAPI + وثيقة السوكت) والطبقة الشبكية الموحّدة وربط QR.
