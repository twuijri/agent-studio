## المشكلة والهدف
المالك يريد إظهار المستودع للعامة بشكل احترافي: README إنجليزي فقط يوضح أن
المشروع مبني على Ekko Studio من EKKOLearnAI ويحفظ حقوقهم ورخصتهم، ثم حماية
`main` من أي دمج غير مصرّح. README الحالي مزيج عربي/إنجليزي مع نسخة كاملة من
README الأصلي داخله.

## القرار والموافقات
- الموافقة: طلب المالك (2026-09-18: «سويلي ريد مي على القيت هوب بشكل احترافي…
  إنجليزي بس… وتحط الرخصة… نفتح المستودع ونأمن المين»).
- فحص الرخصة قبل القرار: `LICENSE` هو BSL 1.1 بترخيص EKKOLearnAI مع منح
  استخدام غير تجاري (شخصي وتعليمي وبحثي) وتحوّل إلى Apache 2.0 في 2029-05-10.
  BSL يسمح بالنسخ والتعديل وإعادة التوزيع مع بقاء الرخصة، فإظهار الفورك غير
  التجاري مع الرخصة والنسب **متوافق**. الحارس `check-personal-license.mjs`
  و`NOTICE.personal.md` وحقول `license: BSL-1.1` في الحزم موجودة ولم تُمس.
- README جديد بالإنجليزية: النسب في أعلى الصفحة، ما يضيفه Core Hub، البدء
  (سيرفر/سطح مكتب)، التطوير، المساهمة، الأمان، قسم الرخصة كاملاً. README الأصلي
  نُقل كما هو إلى `docs/UPSTREAM-README.md` مع تصحيح الروابط النسبية.
- تحديث قاعدة الخصوصية في `docs/TEAM-RULES.md` و`AGENTS.md`: الإظهار قرار المالك،
  الصور تبقى خاصة. لم يُغيَّر وضع المستودع في هذا الطلب؛ الإظهار وحماية `main`
  إجراء منفصل يجريه المساعد بإذن المالك بعد الدمج.
- ملاحظة للمالك: الوثائق تذكر أسماء نطاقات سيرفره (`test.example.com`،
  `studio.example.com` في اختبار) وليست أسراراً؛ إبقاؤها أو تعميمها قراره قبل الإظهار.
