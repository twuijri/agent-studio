## المشكلة والهدف

المنصات: macOS ولينكس لأن الخطوات تطلب ملفات محدّث `latest*.yml` لا ينتجها

يقارن بصمة الملف بالبايت، وسحب git على ويندوز يحوّل نهايات الأسطر إلى CRLF
فتختلف البصمة رغم أن النص نفسه.

  بيان macOS «إن وجد» بدل الفشل، وتعطيل مهمة دمج بيان المحدّث (`if: false`)؛
  «وضع الإصدار كأحدث» تعتمد على مهمة البناء مباشرة.
- حارس الرخصة: يقرأ الملف نصاً ويوحّد `\r\n` إلى `\n` قبل حساب البصمة نفسها
  (لا يُضعف الفحص: المحتوى هو ما يُقارن)، و`.gitattributes` يثبّت `LICENSE`
  على LF لكل السحوبات.
