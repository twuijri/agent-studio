## المشكلة والهدف
الإعداد العام يتبع لغة الواجهة، لكن أسئلة الوكيل وحقول المهام المجدولة وبعض
تفاصيل الكانبان لا تحدد اتجاه النص مستقلًا عنها. نضيف أساسًا مشتركًا للتطوير
المستقبلي ونغطي هذه المواضع دون إعادة كتابة الواجهة أو تغيير البيانات.

## القرار والموافقات
أذن المستخدم بالتنفيذ والاختبارات وقواعد الاستخدام، ثم أذن صراحة برفع طلب دمج
مستقل بعد نجاح الفحوص، مع إبقاء الدمج له وحده. بدأ الفرع من origin/main عند
8499c8a1؛ دمج صاحب المشروع قواعد الفريق في 1287cc26 أثناء التنفيذ، وأُعيد تأسيس
فرع المهمة عليها دون تعارض أو تغيير فرق التطبيق والاختبارات. لا نشر صورة أو تعديل للسيرفر. الاتجاه العام
وMarkdown القائم محفوظان.

## الملفات والتأثير
مكونات وأدوات اتجاه المحتوى في العميل، أسئلة المحادثة والجماعية والإشعارات،
الكانبان والمهام المجدولة، اختبارات ووثيقة سياسة التطوير. لا قاعدة بيانات أو Docker.

## الفحوص
بيئة محلية: Node.js 24 وnpm 11، ومتصفح Chrome المثبّت عبر PLAYWRIGHT_CHANNEL=chrome.

- `npm run build`: نجح (العميل والخادم وفحص الأنواع والرخصة).
- `npm run test:coverage -- --maxWorkers=4`: نجح، 5634 اختبارًا ناجحًا و14 متخطّى
  عبر 680 ملفًا ناجحًا و7 ملفات متخطاة حسب إعداد الاختبارات الاختيارية.
- اختبارات الاتجاه المركزة للمتصفح مع تبديل اللغة: 7 ناجحة؛ إعادة الحالات الست
  بعد إضافة انتظار اكتمال فتح اللوحة: 6 ناجحة، مع مراجعة الصور يدويًا.
- `npm run harness:check` و`npm run test:personal`: نجحا بعد تحديث فرع الأساس؛
  8 اختبارات شخصية ناجحة. حارس اعتماد اتجاه المحتوى: 4 اختبارات ناجحة.
- فحصا المتصفح الكاملان من ذاكرة Vite جديدة: كل منهما 209 ناجحة وتعثر اختبار
  معاينة XLSX بمهلة انتظار ظهور ورقة العمل. نجح الاختبار نفسه ثلاث مرات متتالية
  منفردًا دون تعديل عليه. يثبت trace الجولة الثانية أن الصفحة أُعيد تحميلها بعد
  طلب عامل XLSX؛ اختفت لوحة المعاينة. سبب إعادة التحميل غير محسوم (إعادة تهيئة
  اعتماديات خادم التطوير احتمال، لا تشخيص مؤكد). إعادة المجموعة على نفس ذاكرة
  التطوير المجهزة نجحت: 210 اختبارات، دون تغيير التطبيق أو الاختبار أو مهلته.
  الأمر: `PLAYWRIGHT_CHANNEL=chrome PLAYWRIGHT_PORT=4192 npx playwright test --workers=4`.
  مصدر التطبيق والاختبارات المفحوص: `84742fba`؛ التعديل اللاحق يوثق النتائج فقط.
- فحص سجل المهمة ومحاكاة الدمج مع `origin/main` نجحا، دون دمج إلى الفرع الرئيسي.

المتصفح المدار لم يكن متاحًا بإصدار Playwright المطلوب، فاستُخدم Chrome عبر
الخيار الموجود أصلًا بالمشروع دون تغيير إعداداته. صُححت صيغة fixture المهمة
المجدولة لتطابق استجابة API الفعلية. حالات المتصفح تستعمل بيانات وواجهات
تجريبية، ولا تثبت عمل نماذج أو قنوات مدفوعة أو بيانات إنتاج.

## المخاطر والرجوع
لا نفرض اتجاهًا واحدًا على الصفحات ولا نغيّر ترتيب الأعمدة أو القيم المحفوظة.
الاختبارات الآلية تضمن العقود المسجلة لا التصنيف الدلالي لكل نص مستقبلي.
الرجوع كودي فقط ولا يتطلب ترحيل بيانات.
