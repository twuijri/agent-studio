# هوية كور هب وتوافق إعادة تسمية المستودع

المسؤول: twuijri
الفرع: feat/core-hub-branding
الحالة: review

## المشكلة والهدف
طلب المالك اعتماد Core Hub / كور هب والشعار المرفق بدل الاسم المؤقت Agent Studio،
وإعادة تسمية المستودع إلى core-hub. تشمل الهوية الويب وPWA وسطح المكتب والوثائق.
لا تشمل إعادة تسمية الوكلاء الأصليين أو حذف الرخصة والنسب أو نقل البيانات.

## القرار والموافقات
التنفيذ وفتح طلب دمج مستقل مأذونان بطلب المالك. لا يدمج المساعد في main.
يجب دمج توافق سير العمل أولًا قبل إعادة تسمية الريبو: مسار الصور الحالي يتحقق
من اسم agent-studio حرفيًا. وافق المالك صراحة على رفع PR أولًا ثم تغيير اسم الريبو
بعد دمجه بنفسه. لا نشر latest أو تعديل للسيرفر.
يبقى عنوان GHCR القديم ومعرّفات التطبيق ومسارات التخزين متوافقة مع التثبيتات الحالية.

## الملفات والتأثير
أسماء العرض والترجمات والأيقونات وبيانات الحزم ووثائق التشغيل ومسار الصورة الشخصية.
يشمل عميل Android التجريبي الموجود داخل هذا المستودع، وليس تطبيق المطور الرسمي
أو تطبيق iOS غير الموجود هنا. مرجع التنفيذ: [دليل الهوية](../CORE-HUB-BRANDING.md).
تُحفظ السجلات التاريخية وأسماء البروتوكولات والرخص ونسب المساهمات.

## الفحوص
الأساس origin/main عند 51db3b587c9070ef9665a06a5bc1b4d66872e0bd، وأعيد جلبه
ولم يتغير أثناء الفحص. بيئة الاختبار Linux، Node 24، npm 11، Chrome محلي.
نجح تثبيت الحزم من ملف القفل `npm ci --ignore-scripts` ثم `npm rebuild node-pty`.
نجح بناء الإنتاج `npm run build`، وفحص `npm run harness:check`، و8 اختبارات
`npm run test:personal`. نجح التشغيل النهائي للتغطية
`npm run test:coverage -- --maxWorkers=4 --testTimeout=15000`:
5700 اختبار ناجح و14 متجاوزًا (686 ملفًا ناجحًا و7 متجاوزة).
نجح بناء كود Electron `npm --prefix packages/desktop run build`.
نجح `gradle assembleDebug` لعميل Android باستخدام JDK 17 وGradle 8.9 وSDK 34؛
هذا بناء محلي وليس نشر APK أو اختبار جهاز فعلي.
فحص بصري لصفحة الدخول بالإنجليزية والعربية وفي المظهرين الفاتح والداكن:
الاسم والشعار والاتجاه صحيحون. نجح اختبار عدم تغيير الرخصة وثوابت Docker والهوية
الداخلية، ونجح تكرار أداة العلامة دون تغيير إضافي (idempotency).
أول تشغيل للمتصفح: 220 ناجحًا و3 إخفاقات؛ عُدّل توقع الاسم العربي القديم،
أظهر التشغيل التالي إعادة تحميل للصفحة أثناء المعاينات، ومعه فشل Groq عند reload.
نتيجته النهائية: 220 ناجحًا من 223، وثلاث حالات احتاجت إعادة.
نجحت الحالات الثلاث في إعادة منفردة بworker واحد على المنفذ نفسه (19.2 ثانية)،
دون تغيير كود المعاينة/Groq أو إضعاف أي اختبار. لا تُخفى إعادة المحاولة من التقرير.
لا تدّعي هذه الاختبارات المحلية اختبار تثبيت/ترقية فعليًا على Windows أو macOS.
لا توجد خريطة معرفة مولدة في .ua؛ الفحص مباشر ومحدّد للمصادر.

## المخاطر والرجوع
تغيير package.name لسطح المكتب قد ينقل Electron userData، لذلك يظل ثابتًا.
يحظر تغيير HERMES_HOME أو Web UI home أو أسماء الفوليومات أو مسارات API/IPC.
يبقى LICENSE بنفس البصمة. تغيير الريبو لا يُنفذ قبل دمج توافق البناء.
التراجع عن الهوية لا يحتاج ترحيل قاعدة بيانات.

## التسليم والخطوة التالية
فرع مستقل للمراجعة، ولا يزال اسم المستودع agent-studio. بعد اكتمال الفحوص يرفع
طلب إلى main وتُحدّث نسخة test حسب التفويض الدائم؛ لا يغير ذلك latest أو السيرفر.
بعد مراجعة المالك ودمجه فقط تأتي إعادة تسمية
المستودع وتحديث origin والتحقق من الخصوصية والصلاحيات وصورة GHCR القائمة.
