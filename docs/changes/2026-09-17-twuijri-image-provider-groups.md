# تمييز مصادر مزوّدي الصور

المسؤول: twuijri
الفرع: feat/image-provider-groups
الحالة: review

## المشكلة والهدف
قائمة مزوّدي الصور تعرض مزوّدي هرمز والمزوّدين المخصصين دون تمييز مصدرهم.
الهدف توضيح الفرق دون وصف أي مزوّد بأنه معتمد أو مضمون التشغيل.

## القرار والموافقات
وافق المستخدم على التنفيذ: مجموعتان ديناميكيتان بحسب مصدر الخيار، مع توضيح
التوافق. بدأ الفرع من main عند 5dd5d487، ثم حُدّث دون تعارض إلى f1c59a6b.
وافق المالك لاحقًا على رفع طلب دمج مستقل؛ الدمج في main يبقى له. لا تغيير
للسيرفر أو latest ولا دمج تلقائي.

## الملفات والتأثير
لوحة النماذج المساعدة وترجماتها واختبارات العميل والمتصفح فقط.
لا تغيير لقيم المزوّدين أو النماذج المحفوظة أو عقود الطلبات أو الخلفية.

## الفحوص
- أُعيدت الفحوص التالية بعد دمج main عند f1c59a6b (نتيجة الدمج e39b1f00)،
  ونجحت: البناء والحارس والشخصية و19 حالة مركزة و18 حالة متصفح.
- Node 24: اختبارات auxiliary-models-panel وi18n-direction وcontent-direction-contract: نجحت 19 حالة.
- متصفح Chrome: image-provider-groups وprovider-models: نجحت 18 حالة؛ أُعيدت حالتا الصور بعد تحسين fixture وانتظار اكتمال الظهور، ونجحتا.
- نجح npm run build وnpm run harness:check وnpm run test:personal (8 حالات).
- بيانات وخدمات وهمية فقط؛ لا توليد صور مدفوع ولا تعديل سيرفر.

## المخاطر والرجوع
الحفاظ على البحث والاختيارات الحالية وتعطيل المزوّد غير المتاح، وتصفية قدرات
تعديل الصور، وعدم تغيير قوائم المهام الأخرى. الرجوع كودي دون ترحيل بيانات.

## التسليم والخطوة التالية
تنفيذ محلي على فرع مستقل، مأذون رفعه كطلب دمج إلى main. طلب Groq TTS مستقل
برقم 7؛ لا يعتمد هذا التعديل عليه. قرار الدمج للمالك، ولا نشر للإنتاج.
