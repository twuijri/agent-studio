# دليل مساهمة إنجليزي وقالب طلب دمج ثنائي اللغة ومسار fork في قواعد الفريق

المسؤول: twuijri
الفرع: docs/public-contributing
الحالة: review

## المشكلة والهدف
بعد إظهار المستودع، المساهم الخارجي يرى `CONTRIBUTING.md` وقالب طلب الدمج
بالعربية فقط، ولا تشرح القواعد كيف يصل تعديل قادم من fork (بلا صلاحية كتابة)
إلى فرع `test` ليجرّبه المالك. المطلوب: دليل إنجليزي مختصر يحيل إلى القواعد
العربية بوصفها المرجع، وقالب طلب دمج يفهمه الطرفان، وتوضيح خطوة `test` لمن يعمل من fork.

## القرار والموافقات
- الموافقة: طلب المالك (2026-09-18: «كل شي مكتوب صح لأي أحد كيف يرفع بي ار… والتست
  دايم فيه كل التحديثات»).
- `CONTRIBUTING.md` إنجليزي كامل (القواعد الثابتة، مسار fork بسبع خطوات، الإبلاغ)،
  والقواعد العربية `docs/TEAM-RULES.md` تبقى المرجع عند الاختلاف.
- القالب ثنائي اللغة بنفس الأقسام والخانات، وأُضيف بند «لا أسماء نطاقات حقيقية».
- §9-ب: المساهم الخارجي يكتفي بطلب الدمج؛ دمج فرع طلبه في `test` يجريه صاحب
  المشروع أو مساعده بجلب `pull/<n>/head`، فيبقى `test` حاملاً كل التعديلات المفتوحة.
