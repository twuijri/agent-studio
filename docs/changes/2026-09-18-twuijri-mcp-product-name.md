# اسم المنتج في تعليمات أدوات MCP: كور هب لا Ekko Studio

المسؤول: twuijri
الفرع: fix/mcp-product-name
الحالة: review

## المشكلة والهدف
رد Hermes على المالك بعبارة «Ekko Studio» رغم إعادة التسمية. لا يوجد نص بهذا
الاسم يصل للنموذج؛ هو يستنتجه من معرّفات الأدوات `ekko_studio_*` وأسماء خوادم
MCP `ekko-studio-*` التي أبقيناها عمداً للتوافق. المطلوب أن يعرف الوكيل أن
المنتج اسمه كور هب دون تغيير المعرّفات.

## القرار والموافقات
- الموافقة: ملاحظة المالك (2026-09-18).
- تعليمات خادم MCP (التي يستلمها الوكيل عند التهيئة لكل مجموعة أدوات) تبدأ الآن
  بجملة تعريف: المنصة اسمها Core Hub، والبادئة `ekko_studio_` معرّف توافق لا اسم
  المنتج. وصف الأدوات الذي كان يذكر «Hermes Web UI» صار «Core Hub».
- المعرّفات (أسماء الأدوات والخوادم والأوامر) لم تُمس، وفق قرار الهوية.

## الملفات والتأثير
`bin/ekko-studio-mcp.mjs` فقط. يصل للمستخدم عبر صورة السيرفر وتطبيق سطح المكتب.

## الفحوص
اختبارات MCP الأربعة (`hermes-web-ui-mcp`، `hermes-studio-browser-mcp`،
`ekko-studio-mcp-device-screen`، `ekko-agent-mcp`) و`node --check`.

## المخاطر والرجوع
نص فقط. الرجوع بحذف الجملة.

## التسليم والخطوة التالية
