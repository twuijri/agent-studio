## المشكلة والهدف

الجديدة، توقيع ماك ad-hoc، «برامج الجهاز» في الشريط الجانبي وفي الوضع المحلي،
إصلاح طلب الاقتران التلقائي، والصورة العامة.

- رفع رقم النسخة إلى 1.0.1 في `package.json` و`packages/desktop/package.json`
  وملفي القفل فقط؛ لا تغيير في الكود.
- بعد الدمج: وسم `v1.0.1` على رأس `main`، إصدار GitHub بملاحظات مولّدة، ثم
  `desktop-release.yml` (كل المنصات) و`webui-release.yml` و`personal-image.yml`
  بـ `source_ref=v1.0.1` و`publish_latest=true`.
