# المرحلة 5: تطبيقات الجهاز كخوادم MCP للوكلاء (اتصالات التطبيقات)

المسؤول: twuijri
الفرع: feat/device-apps
الحالة: review

## المشكلة والهدف
برامج مثل DaVinci Resolve تسجّل خادم MCP لديها عند Claude Desktop وClaude Code
وCodex فقط؛ لا تعرف كور هب. المالك يريد أن يستخدم Hermes على السيرفر هذه البرامج
الموجودة على جهازه، مع اكتشاف وإذن في التطبيق، وربطاً تلقائياً بالوكلاء على
السيرفر، ودعم ماك وويندوز ولينكس. كما يريد إصلاح بناء الإصدار الذي فشل على كل
المنصات (ضمن الطلب نفسه بطلبه).

## القرار والموافقات
- الموافقة: المالك (2026-09-18: «يالله ابد فيها الحين»، الهيكل المتفق عليه:
  الاكتشاف والإذن في التطبيق، والربط بالوكلاء على السيرفر، ودمج كل التعديلات
  في طلب واحد).
- **الاكتشاف (التطبيق):** `device-agent/mcp-discovery.ts` يقرأ إعدادات Claude
  Desktop (بما فيها امتدادات `.mcpb` المثبتة مع حل `${__dirname}` و`${HOME}`)
  وClaude Code وCodex (محلل TOML فرعي بلا اعتماديات) وCursor وWindsurf، بمسارات
  ماك وويندوز (`APPDATA`) ولينكس (`XDG_CONFIG_HOME`). التطبيقات ذات الإعدادات
  غير القابلة للحل تُعرض ولا تُشارك.
- **الإذن والتشغيل (التطبيق):** المستخدم يختار ما يشاركه (صفحة «اتصالات
  التطبيقات» في الواجهة عبر الجسر)؛ التطبيق يشغّل خادم MCP للبرنامج محلياً كعملية
  stdio ويمرر بايتاتها عبر قناة الجهاز (رسائل `mcp.open/data/close/exit`)،
  بموافقة واحدة لكل تطبيق في كل اتصال (أو «دائماً»)، وسجل نشاط.
- **السيرفر:** المصافحة تعلن قدرة `apps`، والجهاز يرسل `device.apps` بقائمته؛
  تُحفظ في `device-apps.json` (بيت الواجهة). نقطة WebSocket
  `/api/devices/app-session` تعطي عميل MCP أنبوباً خاماً للتطبيق (مصادقة برمز
  المستخدم/البروفايل وربط الأجهزة بالبروفايلات). سكربت `bin/core-hub-device-mcp.mjs`
  خادم stdio عادي يصل بين الوكيل وهذه النقطة، فيعمل مع أي وكيل يدعم MCP.
- **الربط بالوكلاء (السيرفر تلقائياً):** لكل بروفايل مسموح له بالجهاز يُحقن
  إدخال مُدار `device-<جهاز>-<معرّف>-<تطبيق>` في `config.yaml` لـ Hermes وفي إعداد
  Ekko، معلَّم بـ `CORE_HUB_DEVICE_APP=1` فلا يمس خوادم المستخدم، ويُزال عند إلغاء
  المشاركة أو حذف الجهاز، ويُحترم تعطيله يدوياً. التطبيق لا يعدّل إعدادات
  الوكلاء إطلاقاً.
- **الواجهة:** عنصر «اتصالات التطبيقات» في الشريط الجانبي (يظهر فقط من التطبيق
  المرتبط) بصفحة اكتشاف/مشاركة، وقائمة التطبيقات المشتركة تحت الجهاز في صفحة
  الأجهزة. 11 لغة.
- خارج النطاق: خوادم MCP البعيدة (url) لا تُمرر بعد؛ ملفات `.mcpb` غير المثبتة
  لدى Claude لا تُقرأ.
- **إصلاح الإصدار (مدمج هنا بطلب المالك):** حذف بيانات المحدّث `latest*.yml` من
  رفع الإصدار (المحدّث معطّل في هذه النسخة)، وحارس الرخصة يوحّد نهايات الأسطر
  (ويندوز)، و`.gitattributes` يثبّت `LICENSE` على LF.

- `tests/server/device-apps.test.ts`: المخزن، الحقن في Hermes (إضافة/تحديث/إزالة/
  احترام التعطيل/الربط بالبروفايل)، الحقن في Ekko، واختبار **من طرف إلى طرف**:
  مدير المقبس الحقيقي + الوكيل الحقيقي + تطبيق stdio حقيقي + سكربت الجسر الحقيقي
  كعميل MCP، مع رفض البروفايل غير المسموح.
- فحوص الأنواع الثلاثة، `tests/server` و`tests/client` و`tests/desktop` كاملة،
  `harness:check`، `git diff --check`، `tests/personal`.
- لم يُجرَّب مع DaVinci الفعلي (لا ماك هنا)؛ المسار مغطى بتطبيق stdio حقيقي.

  تُزال تلقائياً.
