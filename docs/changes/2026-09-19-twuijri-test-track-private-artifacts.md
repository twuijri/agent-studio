# حذف ملفات التشغيل العامة بعد نشر بناء التست في المستودع الخاص

المسؤول: twuijri
الفرع: fix/test-track-private-artifacts
الحالة: review

## المشكلة والهدف
ملفات التشغيل (Artifacts) في مستودع عام يستطيع أي مستخدم مسجّل في GitHub
تنزيلها، بينما المالك يريد بناءات التست له وحده.

## القرار والموافقات
- الموافقة: المالك (2026-09-19: «ما ابي احد ياخذها»).
- بعد نجاح النشر إلى الإصدار الخاص `latest-test` تحذف وظيفة النشر ملفات
  التشغيل `core-hub-test-*` لهذا التشغيل عبر API (الصلاحية `actions: write`
  موجودة). حُذفت أيضًا ملفات التشغيل السابقة من نفس النوع يدويًا.

## الملفات والتأثير
`.github/workflows/test-track.yml`.

## الفحوص
- تحليل YAML، `harness:check`، `git diff --check`.

## المخاطر والرجوع
- إن فشل النشر تبقى الملفات كما هي للتشخيص. الرجوع بإزالة الخطوة.

## التسليم والخطوة التالية
طلب دمج إلى `main` ثم `test`.
